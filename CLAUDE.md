# Proyek: Website Rental Mobil Jogja

Sumber kebenaran proyek ini ada di `docs/BRIEF-Jogja-Rental.md`. Baca file itu sebelum menulis kode.

- `reference/rental-jogja-demo.html`: demo tampilan dan alur (satu file, data di localStorage). Tiru tampilan dan perilakunya, tetapi jangan salin penyimpanan localStorage atau kredensial demonya.
- `reference/contoh-invoice-konfirmasi.pdf` dan `reference/contoh-pembatalan.pdf`: contoh hasil PDF yang diharapkan (data contoh).
- `assets/logo-jogja-rental.png`: logo resmi (latar transparan; isi latar putih saat ditempel di panel gelap atau PDF).

Aturan utama:
1. Semua teks antarmuka berbahasa Indonesia.
2. Tanpa emoji dan tanpa ikon dekoratif.
3. Mobile-first; uji di lebar 360 px.
4. Notifikasi memakai SweetAlert2.
5. Jangan menulis rahasia atau kredensial di kode; pakai variabel lingkungan.
6. Ajukan rencana dan pertanyaan (bagian 14 brief) sebelum mulai membangun.
